# Hivord — site oficial (identidade laranja)

Site estático com a logo original fornecida, identidade laranja-âmbar e grafite, modo claro/escuro, layout responsivo e cinco páginas.

## Atualizar o GitHub Pages

1. Extraia o ZIP.
2. Envie **todos os arquivos** para a raiz do repositório `vallathar/hivord-site`, substituindo os arquivos existentes.
3. Confirme o commit e aguarde a atualização do GitHub Pages.
4. Preserve `CNAME` com `www.hivord.com.br`. Não é necessário mudar o DNS.

## Atenção

- Os textos jurídicos são minutas e precisam de revisão antes do lançamento.
- A publicidade foi prevista nos textos, mas sua integração e os consentimentos precisam ser implementados no aplicativo.
- A exclusão de conta é atualmente uma solicitação por e-mail, não uma exclusão automática.
- A imagem do telefone na página inicial é ilustrativa.
- O botão de tema está disponível em todas as páginas e salva a preferência no navegador.
