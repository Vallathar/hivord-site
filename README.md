# Hivord — site oficial (versão refeita)

Visual laranja/âmbar e grafite, com a logo original do Hivord, modo escuro e páginas responsivas.

## Atualização no GitHub
1. Extraia o ZIP.
2. Envie os arquivos para a raiz do repositório `vallathar/hivord-site`.
3. Substitua os arquivos de mesmo nome e confirme o commit.
4. Aguarde a publicação e faça Ctrl+Shift+R.

**Importante:** os cinco HTMLs contêm CSS, JavaScript e a imagem da logo embutidos para não depender de carregamento de arquivos separados. Os arquivos `style.css`, `site.js` e `logo-hivord.png` também são fornecidos para manutenção.

**Atenção:** a documentação legal é minuta sujeita a validação. A exclusão de conta por e-mail não substitui o fluxo efetivo no aplicativo. A prévia do telefone é ilustrativa.
