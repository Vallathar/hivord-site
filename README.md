# Site oficial Hivord — GitHub Pages

## Publicação
1. Crie um repositório **público** no GitHub, por exemplo `hivord-site`.
2. Faça upload **dos arquivos dentro desta pasta**, diretamente na raiz do repositório (não da pasta inteira).
3. Acesse Settings → Pages → Build and deployment → Deploy from a branch → `main` / `(root)` → Save.
4. Aguarde a URL `https://SEU-USUARIO.github.io/hivord-site/`.
5. Depois, em Settings → Pages → Custom domain, configure `www.hivord.com.br`.
6. No DNS da Hostinger, crie CNAME `www` → `SEU-USUARIO.github.io` (sem https e sem caminho).
7. Aguarde a verificação e habilite **Enforce HTTPS** quando disponível.
8. Para usar `hivord.com.br` sem www, configure o redirecionamento para `https://www.hivord.com.br` no serviço de domínio, caso disponível.

**Não altere registros MX, SPF, DKIM ou DMARC dos e-mails.**

## Avisos antes da publicação oficial
- As páginas jurídicas são **minutas**; revisar com profissional jurídico.
- Confirmar CNPJ e dados institucionais, regiões de hospedagem, prazos de retenção e configurações reais do AdMob.
- O aplicativo ainda não exibe anúncios; ajustar declarações de privacidade nas lojas conforme o SDK efetivamente implementado.
- Implementar e testar exclusão de conta e dados no backend antes de lançar o app.
- Testar os três endereços de e-mail.
- Não há links de download até a publicação nas lojas.
